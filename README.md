# Flight Rescue

인천공항 국제선 여객편의 실시간 운항정보를 조회하고 지연·결항 상황에서 필요한 행동, 항공사 보상 확인 항목, 여행자보험 확인 항목과 증빙서류를 안내하는 모바일 우선 웹서비스입니다.

## 주요 기능

- 항공편명, 출발 날짜, 출발·도착 구분으로 운항편 검색
- 항공편명의 공백 제거 및 영문 대문자 정규화
- Next.js 서버 Route를 통한 인천국제공항공사 OpenAPI 연동
- 국제선(`typeOfFlight=I`)·여객기(`passengerOrCargo=P`)만 조회
- 화물기, 국내선, 코드셰어 `Slave` 편 제외 및 Master 기준 중복 제거
- 예정시간과 변경시간으로 지연시간 계산. 누락·비정상 시간은 `확인 필요` 표시
- 지연시간 및 결항 여부에 따른 5단계 대응 가이드
- 항공사 보상 가능성, 소비자분쟁해결기준, 여행자보험 확인 안내
- 브라우저 `localStorage`에 임시 저장되는 증빙서류 체크리스트
- 정상, 3시간·6시간·13시간 지연, 결항 발표용 시뮬레이션
- 로딩, 인증키 누락, 호출 한도, API 장애, 빈 결과, 입력 오류 안내
- 단계별 사용자 상황 입력, 조건 기반 행동 체크리스트, 메모와 완료 기록의 기기 저장
- 여객터미널 시설 API 기반 구역·터미널·운영시간 필터와 보수적 시설 추천
- 설치 가능한 웹앱(PWA)과 오프라인 화면, 수동 상태 변경, 재연결 동기화 및 충돌 안내
- 계산 지연시간에 따른 공통 상태 표시(2시간 미만 파랑, 2~4시간 노랑, 4시간 이상 주황, 결항 빨강)
- 상황과 지연 구간에 따라 바뀌는 증빙 목록, 항목별 완료 상태·메모 보존
- 항목마다 확인 장소와 방법, API가 제공하는 현재 시각·게이트 및 확인된 공식 링크 표시
- 실제 운항편 5분 간격 자동 갱신, 수동 새로고침·중지, 백그라운드·오프라인·결항 시 자동 중단
- 공식 공항 지도로 시설 위치 확인. 좌표가 없는 시설에 임의 마커나 이동시간을 표시하지 않음

## 환경변수 설정

1. `.env.example`을 참고해 프로젝트 루트에 `.env.local`을 만듭니다.
2. 공공데이터포털에서 발급받은 일반 인증키 또는 URL 디코딩 인증키를 다음 변수에 설정합니다.

```bash
DATA_GO_KR_SERVICE_KEY=발급받은_인증키
```

`.env.local`은 `.gitignore`에 포함되어 Git에 커밋되지 않습니다. 인증키는 서버 Route에서만 읽으며 클라이언트 번들 또는 브라우저 요청에 포함하지 않습니다.

## 실행 방법

Node.js 20.9 이상과 pnpm을 권장합니다.

```bash

```

브라우저에서 `http://localhost:3000`을 엽니다.

```bash
pnpm test

```

## API 연동

인천국제공항공사 `항공기 운항 현황 상세 조회` API를 사용합니다.

- 기본 경로: `http://apis.data.go.kr/B551177/statusOfAllFltDeOdp`
- 출발편: `getFltDeparturesDeOdp`
- 도착편: `getFltArrivalsDeOdp`
- 조회 가능 기간: API 가이드 기준 조회일 3일 전부터 6일 후
- 고정 요청값: `passengerOrCargo=P`, `type=json`, `searchdtCode=S`

API 응답은 서버에서 다시 `Passenger`, `typeOfFlight=I`, 코드셰어 `Slave` 제외 조건으로 방어적으로 필터링합니다. API 문서의 필드 표기와 예시 응답 간 일부 대소문자 차이(`scheduleDatetime`/`scheduleDateTime`)도 모두 처리합니다.

시설정보는 인천국제공항공사 `FacilitiesInformation/getFacilitesInfo`에서 서버 Route로 가져옵니다. 이 API의 갱신주기는 월 1회이며, 무료 여부·가격·실제 이동시간·혼잡도·입장 조건은 제공하지 않습니다. 시간이 충분한 후보는 이동시간이 없어도 보여주되, 출발 40분 전까지 탑승구로 이동하라는 안내와 현장 동선 확인을 함께 표시합니다. 정확한 이동시간을 확인한 경우 사용자가 직접 입력할 수 있습니다. 시설 위치는 [인천공항 공식 지도](https://www.airport.kr/geomap/ap_ko/view.do?alertType=0&tmnlId=P01&type=2)에서 터미널·층·구역을 대조하도록 안내합니다. 시설 API 사용 권한은 공공데이터포털의 해당 서비스 활용 신청 상태에 따라 달라집니다.

오프라인에서는 최근 성공한 항공편·시설과 사용자 상황·체크리스트·메모를 브라우저 저장소에서 읽습니다. 서비스 워커가 웹앱 화면과 정적 자산을 저장하며 API 요청은 캐시하지 않습니다. 온라인에서는 실제 운항편을 5분 간격으로 확인하고, 탭이 숨겨졌거나 연결이 끊기면 요청하지 않습니다. 재연결 시 최신 API를 다시 조회하며, 실패하면 저장된 정보를 유지하고 오류와 마지막 성공 시각을 보여줍니다. 수동 입력이 공항 정보와 다르면 둘 다 표시하여 사용자가 선택하게 합니다. 브라우저 저장 데이터는 기기·브라우저별로 분리되며 삭제하면 복구되지 않습니다.

증빙서류 목록은 맞춤 상황 기준으로 별도로 갱신됩니다. 2시간 미만은 보상 증빙을 요구하지 않으며, 2시간·4시간·13시간과 결항을 경계로 목록이 바뀝니다. 숙소·교통·보험·수하물 항목은 해당 상황을 선택한 경우에만 표시됩니다. 체크한 항목의 ID는 목록에서 잠시 사라져도 보존합니다.

상단의 ‘지금 해야 할 행동’은 맞춤 행동 체크리스트와 같은 조건에서 우선순위가 높은 항목을 보여줍니다. 영수증 보관 행동은 4시간 이상 지연 또는 결항에서만 추가됩니다. 예정·변경시각과 탑승구의 조회시간은 각각 보조 정보로 표시합니다.

## 대응 단계 기준

| 조건 | 단계 |
| --- | --- |
| 2시간 미만 | 운항정보 확인 |
| 2시간 이상 4시간 이내 | 항공사 보상 가능성 및 지수형 보험 확인 |
| 4시간 초과 12시간 이내 | 항공사 보상 및 실비형 보험 확인 |
| 12시간 초과 | 장시간 지연 대응 |
| 결항 | 대체편·환불·보험 확인 |

결항은 계산된 지연시간보다 우선합니다. 120분, 240분, 720분 경계는 단위 테스트로 검증합니다.

## 공식 기준과 한계

- 소비자분쟁해결기준 안내는 한국 국제여객 기준의 지연 구간별 배상 검토 비율(2~4시간 10%, 4~12시간 20%, 12시간 초과 30%)을 참고합니다.
- 이 비율은 자동 지급되는 확정 보상금이 아니라 분쟁 해결을 위한 기준입니다.
- 기상, 공항 사정, 안전운항 조치, 항공사 귀책 여부 등에 따라 보상이 제한될 수 있습니다.
- 여행자보험은 지수형·실비형·결항 특약별 조건이 다르며 보험사와 상품 약관 확인이 필요합니다.
- 화면의 지연시간은 API의 예정시간과 변경시간 차이입니다. 실제 목적지 도착 지연시간이나 법적 보상 확정 기준이 아닙니다.
- 운항정보는 인천공항 API 갱신 및 항공사 발표 시점에 따라 실제 현장 정보와 차이가 날 수 있습니다.
- 이 서비스는 보험금 자동 판정 또는 법률 자문을 제공하지 않습니다.

## 개인정보와 저장

로그인, 회원가입, 개인정보 입력·저장 기능은 없습니다. 최근 운항·시설 정보, 사용자가 선택한 상황, 체크리스트 완료 상태와 메모는 사용자의 브라우저에만 저장되며 서버로 전송되지 않습니다. 과거 운항 데이터베이스도 운영하지 않습니다.
